Copy Link
====
Component that allows users to copy the current page link to the clipboard.

## Features
* Provides a button to copy the current URL to the clipboard
* Shows a confirmation message after copying ("Link Copied")
* Configurable icon for the copy button

### Configuration Properties
1. `./copyLinkIcon` - Path to the copy link icon (DAM asset)

## BEM Description
```
BLOCK copy-link-button
    ELEMENT gu-copy-link
    ELEMENT gu-copy-icon
    ELEMENT gu-copy-link__text
```
