Contributors
====
Component to display a list of contributors/authors for a page or section.

## Features
* Lists contributors with initials and full names as tooltips
* Each contributor is displayed as a circle with their initials
* Can be used on pages or in sidebars

### Configuration Properties
This component does not have configurable dialog properties. Contributors are sourced from the page metadata model.

## BEM Description
```
BLOCK wrapper
    ELEMENT contributor
    ELEMENT circle
```
