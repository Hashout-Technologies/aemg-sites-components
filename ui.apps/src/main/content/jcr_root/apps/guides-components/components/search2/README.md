Search 2
====
Quick search component written in HTL for searching site content.

## Features
* Provides a search input with configurable icon
* Displays search results dynamically
* Accessible with ARIA roles and labels

### Configuration Properties
1. `./searchIcon` - Path to the search icon (DAM asset)

## BEM Description
```
BLOCK cmp-search
    ELEMENT cmp-search__form
    ELEMENT cmp-search__field
    ELEMENT cmp-search__icon
    ELEMENT cmp-search__loading-indicator
    ELEMENT cmp-search__input
    ELEMENT cmp-search__clear
    ELEMENT cmp-search__clear-icon
    ELEMENT cmp-search__results
```
