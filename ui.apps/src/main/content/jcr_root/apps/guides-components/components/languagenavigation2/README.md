Language Navigation 2
====
Language navigation component written in HTL for switching between site languages.

## Features
* Displays a language selector button with configurable icon
* Renders a navigation tree for available languages


### Configuration Properties
1. `./languageNavIcon` - Path to the language navigation icon (DAM asset)

## BEM Description
```
BLOCK language-selector
    ELEMENT language-selector__toggle
    ELEMENT language-selector__icon
BLOCK cmp-languagenavigation
```
