Back to Top Button 
====
A button component that allows users to quickly scroll back to the top of the page.

## Features
* Appears after scrolling down a configurable distance
* Smooth scrolls to the top when clicked
* Customizable icon and position

### Configuration Properties
1. `./showAfterScroll` - Number of pixels to scroll before the button appears (default: 200)
2. `./icon` - Icon to display in the button (optional)
3. `./position` - Position of the button on the screen (e.g., bottom-right)
